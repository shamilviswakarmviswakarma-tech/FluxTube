# NovaTube Android Home (experimental module)

This is a separate native Android application inside the FluxTube repository. It does not replace or modify the existing Flutter FluxTube app.

## Design
- AMOLED black background (#000000)
- Electric blue accent (#1677FF)
- Jetpack Compose + Material 3
- Home feed with search, categories, Shorts visibility filter, sample video cards and bottom navigation

## Build
Open the `novatube-android` directory in Android Studio, use JDK 17, sync Gradle, then run the app.

## Current limitations
This is a UI prototype with sample video data. Search, account, real feeds, playback, AI services and navigation destinations are not connected yet. The module does not download YouTube media.
